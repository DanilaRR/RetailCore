# Webstore Frontend

Vue 3 and Vite frontend for the Webstore application.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

The development server usually starts on `http://localhost:5173`. If the port is busy, Vite prints the next available URL.

The frontend calls:

- Auth API: `http://localhost:8082`
- Items API: `http://localhost:8081`
