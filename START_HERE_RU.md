# Начните здесь

Для первого запуска используйте Docker:

```bash
docker compose up -d --build
```

Откройте `http://localhost:5173`.

Для локальной разработки используйте четыре терминала:

```bash
make db-start
make security-dev
make items-dev
make frontend-dev
```
